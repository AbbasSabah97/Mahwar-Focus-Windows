# مِحور Focus | Windows

برنامج عربي مستقل لإدارة المهام والتركيز والإنتاجية، مبني باستخدام **Python + PySide6 + SQLite**. يدعم Windows 10/11 بنظام 64 بت.

## المزايا

- لوحة قيادة للمهام المفتوحة والمنجزة والمتأخرة ووقت التركيز.
- مهام قابلة للإضافة والتحرير والحذف والبحث والتصنيف حسب المشروع والأولوية والحجم.
- التخطيط الأسبوعي من السبت إلى الجمعة، مع أهداف أسبوعية وقاعدة **1-3-5**.
- تذكيرات Windows مع دعم التأجيل لعشر دقائق، وتكرار يومي وأسبوعي وشهري.
- مؤقت تركيز 25 أو 50 دقيقة واستراحة 5 دقائق وسجل جلسات التركيز.
- مراجعة أسبوعية للأعمال المنجزة والعقبات وخطط التحسين.
- نسخ احتياطي JSON واستعادة البيانات، مع تخزين SQLite محلي.
- أيقونة خضراء بعلامة صح بيضاء، وواجهة عربية من اليمين إلى اليسار.

## بناء وتنزيل التطبيق EXE من GitHub

1. افتح قسم [Actions](https://github.com/AbbasSabah97/Mahwar-Focus-Windows/actions).
2. اختر **Build Mahwar Focus for Windows**.
3. افتح آخر تشغيل ناجح، ثم من **Artifacts** نزّل **MahwarFocus-Windows-Portable**.
4. فك ضغط الملف ثم شغّل `MahwarFocus.exe`. لا تحتاج إلى تثبيت Python.

## تشغيل من المصدر

يتطلب Python 3.12:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe bootstrap_source.py
.\.venv\Scripts\python.exe run.py
```

للبناء يدوياً: `python -m pip install -r requirements-build.txt`، ثم راجع ملف GitHub Actions.

## تخزين البيانات والتذكيرات

تُحفظ قاعدة البيانات في `%APPDATA%\MahwarFocus\mahwar.db`. لا تحتاج إلى حساب خارجي. تعمل التذكيرات عندما يكون البرنامج مفتوحاً أو في شريط النظام؛ لن تعمل إذا أُغلق بالكامل أو كان الجهاز مطفأً. ملف EXE غير موقّع رقمياً، وقد يظهر تحذير Windows SmartScreen عند تشغيله للمرة الأولى.

**ملاحظة:** النسخة الحالية تطبيق مستقل مستوحى من أفضل مبادئ التخطيط، وليست نسخة رسمية من Microsoft To Do. 

## تحسينات الواجهة (نوفمبر 2026)

- مربّع اختيار عصري **✓** لكل مهمة بدلاً من زر إنجاز نصّي، مع شطب عنوان المهمة المكتملة.
- إكمال المهمة المتكررة يحفظ وقوعها المنجز ويضيف موعدها التالي كسجل مستقل.
- اختيار التاريخ والساعة والدقائق من حقلين منفصلين في نموذج المهمة.
- قائمة تنقّل يمينية بأيقونات متجهية وتمرير سلس وشريط تمرير حديث.
- تحديث تاريخ لوحة القيادة تلقائياً عند انتقال اليوم، حتى مع استمرار تشغيل التطبيق.
- إزالة العبارة غير المطلوبة أسفل القائمة الجانبية.

المهام الموجودة والنسخ الاحتياطية القديمة محفوظة ولا تتطلب تغيير ملف قاعدة البيانات.

## تحسينات اختيار الوقت والتصميم

- وقت **12 ساعة** مع خيارات مستقلة للساعة (01–12) والدقائق (00–59) والفترة **AM صباحاً / PM مساءً**. تُحفظ المواعيد داخلياً بصيغة ISO على نظام 24 ساعة لضمان سلامة التذكيرات والفرز.
- استبدال أسهم القوائم البدائية برمز سهم متجهي، وتقويم واضح بلا أزرار زيادة ونقصان القديمة.
- إلغاء الخلفية المستقلة لحاوية الشعار والاسم في الشريط الجانبي.
- إنجاز وإعادة فتح المهام عبر مربع اختيار أخضر فقط، من دون زر نصّي إضافي.

## نسخة النظام الواحد والمخطط الأسبوعي الجديد

- **تشغيل نسخة واحدة لكل مستخدم Windows:** فتح البرنامج مرة أخرى يعيد إظهار النافذة الحالية ولا ينشئ أيقونة ثانية في شريط النظام. للإشعارات المستمرة أغلق النافذة إلى شريط النظام وليس من أمر «إنهاء البرنامج».
- **الساعة الحية:** التاريخ العربي والوقت (HH:MM:SS AM/PM) من ساعة الجهاز، مع تحديث كل ثانية.
- **التحية السياقية:** صباح الإنجاز قبل الظهر، ومساء الإنجاز من الساعة 12 ظهراً، دون إعادة تشغيل.
- **مخطط أسبوعي واسع:** بطاقات يومين في كل صف بدلاً من ضغط سبعة أعمدة، مع أسماء المهام كاملة، موعد 12 ساعة، صندوق الإنجاز، وتعديل وإضافة، وتمرير عمودي.
- **ملاحظة ترقية مهمة:** أغلق **كل النسخ القديمة** من التطبيق في شريط النظام مرة واحدة قبل تشغيل هذا الإصدار؛ آلية منع التكرار تعمل بين نسخ الإصدار الجديد فقط. بيانات SQLite لا تتغير.

## إصلاح سطر التاريخ والوقت (تحديث نوفمبر 2026)

- لم يعد التاريخ العربي والوقت الإنجليزي في QLabel واحد؛ لكل منهما عنصر مستقل مع ضبط اتجاه الكتابة، لمنع انعكاس AM/PM أو التفاف الساعة إلى سطر آخر.
- يظهر التاريخ العربي إلى اليمين، والساعة بنظام 12 ساعة إلى جواره مع فاصل لطيف، ويُحدَّثان كل ثانية.
