# مِحور Focus — Windows

تطبيق سطح مكتب عربي لإدارة المهام والتذكير، والتخطيط الأسبوعي، ومؤقت التركيز Pomodoro، ومراجعات الإنتاجية. مبني بـ Python وPySide6 وSQLite.

**الألوان:** `#424359`، `#3E8C6F`، `#618C7C`، `#B4D9CB`، `#F2F2F2`.

**طريقة التنزيل:** افتح قسم Actions > Build Mahwar Focus for Windows > آخر تشغيل ناجح > Artifacts > MahwarFocus-Windows-Portable. فك الضغط وشغّل `MahwarFocus.exe`.

يُولّد GitHub Actions ملفات البرنامج الأصلية من حزمة مصدر مضغوطة موثقة داخل `bundle/`، ثم يشغّل اختبارات Python وQt، وينشئ ملف EXE باستخدام PyInstaller. يُنشر كود Python المستخرج إلى المستودع تلقائياً بعد نجاح البناء عند السماح بذلك.

التذكيرات تعمل عند تشغيل البرنامج أو بقائه في شريط النظام، ولا تعمل إذا كان الحاسوب مطفأ. لا تحتاج إلى حساب أو اتصال إنترنت لحفظ البيانات. التطبيق مفتوح المصدر للاستخدام الشخصي، دون نسخ الشيفرة الأصلية من Microsoft To Do.
